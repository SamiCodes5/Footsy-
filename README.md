# Footsy — Online Footwear Shopping Website

Footsy is a beginner-friendly front-end e-commerce website for browsing footwear. It is built with HTML, CSS, and vanilla JavaScript.

## Features
- Responsive layout for desktop and mobile
- Product catalogue with footwear categories
- Search, category filters, and sorting
- Add to bag, remove items, and adjust quantities
- Automatic subtotal calculation
- Demo checkout notice (no real payments)
- Product image fallback if an external image is unavailable

## Technologies
- HTML5
- CSS3
- JavaScript

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a web browser.

No installation or build step is required. Product photos are loaded from Unsplash, so an internet connection is needed for those images.

## Group work distribution (5 members)

4. Shopping bag and price calculation

## Project note
This is an educational front-end demo. It does not include user accounts, a database, order storage, or real payment processing.
